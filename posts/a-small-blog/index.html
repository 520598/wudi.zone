给文字一个自己的地方

从一份 Markdown 开始，写文章、改配色，再把更新交给自动发布。一个小小的博客，也可以慢慢长大。

一直想有一个可以长期放文字的地方。不需要很热闹，能打开、能阅读，也能在想起的时候接着写。

从简单的文件开始

文章放在 Markdown 文件里。标题和段落很容易写，换一台设备也能在 GitHub 网页中继续编辑。

留下一点自己的颜色

我喜欢温暖的纸色与安静的绿色。也许过一阵子会换一种，但文字还是这些文字。
